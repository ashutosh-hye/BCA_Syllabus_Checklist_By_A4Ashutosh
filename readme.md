# Syllabus Tracker

A lightweight, multi-course web application that helps college students track syllabus completion across subjects, units, chapters, and topics with real-time cloud sync.

## Features

- **Multi-Course & Semester Support**: Switch between courses and academic years directly from the app.
- **Hierarchical Progress Tracking**: Expandable units, chapters, and subtopics with progress bars at every level.
- **Search & Filters**: Quickly filter by pending or completed topics and search across chapters.
- **Cloud Sync**: Google Sign-In backed by Firebase Authentication and Cloud Firestore to sync progress across devices.
- **Dark & Light Mode**: Built-in theme toggle with persistent preference.
- **Admin Dashboard**: Role-based overview to monitor student progress by course and year.

## Tech Stack

- **Frontend**: HTML, CSS, Vanilla JavaScript
- **Auth & Database**: Firebase Authentication & Cloud Firestore
- **Hosting**: GitHub Pages

## Deployment

1. Push `index.html`, `style.css`, `app.js`, and `README.md` to your GitHub repository.
2. Enable **GitHub Pages** under **Settings → Pages** (deploy from the `main` branch root).
3. Add your GitHub Pages domain to **Authorized domains** in Firebase Authentication.
